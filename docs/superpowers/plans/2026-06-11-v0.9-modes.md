# AI Glass v0.9 — 소진 예측 재설계 + 메뉴바/웨이브 모드 + 재미 5종

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**확정 사항 (사용자 선택):**
- 메뉴바: 기본 **C(오늘 누적)↔B(소모 속도) 6초 로테이션**, 설정에서 모드 선택: `todayAndBurn`(기본)/`serviceRotation`/`maxPercent`(기존)/`minimalDot`
- 웨이브: 현재 펄스 바 = 스타일 A, 추가 스타일 옵션화: `pulseBars`(기본)/`smoothWave`(연속 사인 물결 곡선)/`waterFill`(사용량 %가 수위, burn rate가 찰랑임)/`orbGlow`(숨쉬는 그라데이션 점)
- 재미 옵션(설정 "재미" 섹션 토글): 마일스톤(on)/신기록(on)/스트릭(on)/주간 리포트(on)/사운드(off)
- 소진 예측 재설계 (스크린샷 피드백): 5h는 **자기 윈도우 리셋 전 소진 시만** ⚠️, 주간은 **일 단위 추정 "~N일"** + 주간 리셋 전 소진 시만, 윈도우 명시

## A1: 코어 — 소진 예측 재설계 (TDD)

1. **DailyStatsStore에 percent 스냅샷 테이블** — `CREATE TABLE IF NOT EXISTS percent_snapshots(day TEXT, service TEXT, kind TEXT, percent REAL, PRIMARY KEY(day, service, kind))`. `recordPercentSnapshot(service:kind:percent:day:)` (REPLACE — 하루의 마지막 관측값), `percentSnapshots(service:kind:days:) -> [(day: Date, percent: Double)]` 오름차순.
2. **주간 일일 소모율** — `DepletionEstimator.weeklyDailyRate(snapshots:) -> Double?`: 연속 일 페어의 (다음날% - 전날%) 중 **양수만** 평균 (리셋 걸친 음수 페어 제외), 페어 < 1이면 nil. `weeklyDepletion(current:rate:resetsAt:now:) -> Depletion?`: daysTo100 = (100-current)/rate → etaTo100, willDepleteBeforeReset.
3. **Depletion에 windowKind 필드 추가** — 기존 `Depletion`에 `kind: LimitWindow.Kind` 포함 (호출부 보정).
4. **UsageStore.depletion(for:now:) 재설계** — 최댓값 윈도우 하나가 아니라: ① session5h 윈도우: 기존 분 단위 기울기 추정, **그 윈도우 resetsAt 기준** willDepleteBeforeReset일 때만 반환 ② weekly: percent_snapshots 기반 weeklyDepletion (statsStore 주입 필요 — UsageStore가 SQLite를 모르므로 **App 레벨 계산으로 이동**: `DepletionEstimator`에 순수 함수로 두고 App이 조합. UsageStore.depletion은 session5h 전용으로 단순화). 반환: `[Depletion]` (0~2개).
5. **EventEngine depletionRisk** — Depletion.kind 포함 메시지: 5h → "이 속도면 {Xh Ym} 후 5h 한도 소진 (리셋 전)", weekly → "이 추세면 약 {N일} 후 주간 한도 소진". 쿨다운 유지(서비스+kind별).
6. **App 배선** — refresh에서 percent 스냅샷 기록(서비스×kind 현재값, 하루 1회 이상 — REPLACE라 매번 OK), depletions 계산 조합. UI(개요 행)도 윈도우별 경고 줄: 5h 줄 아래/주간 줄 아래 각각, 문구 위와 동일.
7. 테스트: weeklyDailyRate(양수 페어만/부족 시 nil), weeklyDepletion 일 계산, session5h own-reset 규칙, percent_snapshots 왕복.

커밋: `feat: 소진 예측 재설계 — 윈도우별 규칙 + 주간 일단위 추정 (v0.9 A1)`

## A2: 코어 — 재미 로직 (TDD)

1. **마일스톤** — `MilestoneTracker` (core): thresholds [100M, 250M, 500M, 1B, 2B, 5B], `check(todayTokens:) -> Int?` 마지막 통과 임계 반환(중복 방지 내부 상태 — 날짜 바뀌면 리셋: `check(todayTokens:day:)`). HUDEvent kind `.milestone` 추가 (HUDView 아이콘 `party.popper.fill`/.yellow).
2. **신기록** — `DailyStatsStore.maxDailyTokens(excludingDay:) -> Int?` (일별 토큰 합 최대, 오늘 제외). App에서 todayTokens > 종전최대 && 종전최대 > 0 → 하루 1회 이벤트 (kind `.record`, 아이콘 `trophy.fill`/.orange, 부제 "종전 {K/M}").
3. **스트릭** — `DailyStatsStore.streakDays(endingOn:) -> Int` 오늘부터 거꾸로 연속 토큰>0 일수. 아침 브리핑 부제 끝에 " · {N}일 연속 🔥" (N ≥ 2일 때).
4. **주간 리포트** — `BriefingEngine` 확장: 월요일 morning이면 특별판 — BriefingData에 `lastWeekTokens/lastWeekCost/prevWeekTokens/lastWeekTopProject` 추가(App이 statsStore로 채움), 제목 "주간 리포트 📊", 부제 "지난주 {tokens} (~${cost}) · 주로 {proj} · 전주 대비 {+N%}".
5. 테스트: 마일스톤 중복/날짜 리셋, 신기록 쿼리, 스트릭 계산(중간 공백), 월요일 분기.

커밋: `feat: 마일스톤/신기록/스트릭/주간 리포트 (v0.9 A2)`

## A3: UI/셸 — 메뉴바 모드 + 웨이브 스타일 + 사운드 + 설정

1. **메뉴바 모드** — `AppSettings.menubarMode: String` enum 4종(기본 todayAndBurn). App: 6초 Timer로 title 갱신(모드별 텍스트: todayAndBurn → "✦ 612M" ↔ "✦ 38K/m"(burn 0이면 누적만 고정), serviceRotation → "● C 49%"(점은 텍스트 ●+색은 attributedTitle 또는 SF심볼 폴백 — NSStatusItem attributed 색 적용), maxPercent → 기존, minimalDot → "✦"만 + 위험도색 attributed). 가벼운 title-only 타이머 (collect 호출 금지).
2. **웨이브 스타일** — `AppSettings.waveStyle` 4종. HUDView WavePill 렌더 분기:
   - pulseBars: 현재 그대로
   - smoothWave: Canvas/Path로 연속 사인 곡선 2겹(서비스 그라데이션 stroke), 진폭=activityLevel
   - waterFill: 알약 내부 수위 = 5h 사용량 %(표시 서비스), 표면 찰랑임 진폭 = burn rate, 서비스 색 반투명 채움
   - orbGlow: 작은 그라데이션 원이 숨쉬기(스케일+글로우), 색 = 서비스 혼합
   각 스타일 동일 입력(share/activityLevel/percent) 사용, 30fps TimelineView 재사용.
3. **사운드** — `Notifier` 또는 신규 `SoundPlayer`: NSSound(named: "Glass")(시스템 사운드) 재생, settings.funSoundEnabled(기본 false)일 때 showHUD에서 이벤트 kind가 알림성(threshold/depletion/milestone/record)일 때만.
4. **설정 창** — 섹션 추가: "메뉴바"(모드 Picker), "웨이브 스타일"(Picker), "재미"(마일스톤/신기록/스트릭/주간 리포트/사운드 토글 — 각 기능 발화 지점에서 가드).
5. **배선** — A2 로직 연결 (마일스톤/신기록 체크는 refresh 디바운스 1분, 스냅샷 기록과 함께), README 갱신.
