# AI Glass v0.10 — Antigravity 토큰 추적 + 사용 잔디

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**배경 (실측 리버스 엔지니어링, 2026-06-12):**
- 최신 Antigravity CLI는 대화를 `~/.gemini/antigravity-cli/conversations/<conversationId>.db` (SQLite)로 저장. `gen_metadata(idx, data, size)` 테이블의 `data`가 protobuf.
- **작은 레코드(~1.1KB)** = 생성(Generation) 요약. 와이어 경로 (필드 번호는 buf 스키마 없이 실측):
  - top `f1`(msg) → `f4`(msg): **`f2` = 입력 토큰**(컨텍스트 누적 성장 패턴 검증됨), **`f3` = 출력 토큰**, `f5` = 컨텍스트 크기(미사용)
  - top `f1` → `f9`(msg) → `f4`(msg) → `f1` = **epoch 초 타임스탬프**
  - top `f1` → `f21`(str) = 모델 표시명 ("Gemini 3.5 Flash (High)")
- 큰 레코드(수십 KB~)는 step 묶음 — 같은 경로 파싱 실패 시 스킵 (작은 요약 레코드만 사용).
- 프로젝트: db 파일명(conversationId) ↔ `history.jsonl`의 `conversationId`→`workspace` 조인.
- 실측 분포: 2,474 레코드, 입력 중앙값 3.8K/출력 231, 일별 합 그럴듯. 모두 동일 모델명.
- **주의**: 비공개 포맷 — 모든 파싱은 방어적(실패 시 조용히 스킵), 결과는 추정치 취급. agy 실행 중 DB 잠금 가능 → `sqlite3_open_v2(SQLITE_OPEN_READONLY)` + busy_timeout 짧게, 실패 시 다음 주기.

## B1: 코어 — AntigravityConversationParser + Collector 통합 (TDD)

1. **ProtoWire** (`Sources/AIGlassCore/ProtoWire.swift`): 최소 protobuf 와이어 워커 — `fields(_ data: Data) -> [Int: [ProtoValue]]` (varint/len-delimited/i64/i32, ProtoValue = .varint(UInt64)/.bytes(Data)). 비정상(field 0 or >80, 길이 초과) 시 빈 결과. 순수 함수 + 테스트(수제 바이트 fixture).
2. **AntigravityConversationParser** (`Sources/AIGlassCore/AntigravityConversationParser.swift`):
   - `generations(dbPath: String) -> [(idx: Int, timestamp: Date, model: String, inputTokens: Int, outputTokens: Int)]` — READONLY sqlite, `SELECT idx, data FROM gen_metadata WHERE size < 50000`, 위 경로 파싱. 타임스탬프/입출력 토큰 누락 레코드 스킵. 모델명은 f21 없으면 "antigravity".
   - 테스트: **실제 포맷 재현 fixture** — 위 경로대로 protobuf 바이트를 빌더 함수로 합성해 임시 sqlite에 넣고 왕복 검증 + 깨진 blob 내성.
3. **history 조인** — 기존 `AntigravityLogParser`에 `conversationWorkspaces(jsonData:) -> [String: String]` (conversationId → workspace lastPathComponent/"~") 추가.
4. **GeminiCollector 확장**:
   - conversations 디렉토리(기본 `~/.gemini/antigravity-cli/conversations`) 의 최근 8일 mtime `.db` 스캔, 파일별 `lastParsedIdx` 캐시(인스턴스) — idx > 캐시만 TokenEvent로: service .gemini, model = 파싱값("Gemini 3.5 Flash (High)" → "gemini-3.5-flash" 정규화: 소문자, 공백→하이픈, 괄호 제거), input/output (cache 0), project = 조인 결과, dedup key "agy:{convId}:{idx}".
   - **CostEstimator**: gemini 단가가 이미 있으므로 자동 적용 (추정).
   - 기존 요청 수 집계(history+log)는 일일 % 추정용으로 유지.
5. **레거시 logs.json 경로는 유지** (변경 없음). 테스트: 통합(임시 디렉토리에 fixture db+history → store에 이벤트+project 검증, 증분).

커밋: `feat: Antigravity 토큰 추적 (대화 DB 리버스 엔지니어링, 추정치)`

## B2: UI — 사용 잔디 (히트맵)

1. **데이터** — `DailyStatsStore.dailyTotals(days:now:calendar:) -> [(day: Date, tokens: Int)]` (서비스 합산, 기존 dailyTotalsByService 재활용 가능하면 신규 메서드 불필요 — 합산 헬퍼만).
2. **HeatmapView** (`Sources/AIGlass/UI/HeatmapView.swift`): GitHub 잔디 스타일 — 최근 15주 × 7일 그리드 (열=주, 행=요일 월~일), 셀 9pt 라운드 2. 강도 = 일 토큰 / (기간 최대 토큰), 5단계 농도 (0 = .quaternary, 1~4 = 민트 계열 농도 — Theme 민트 기반, 다크/라이트 시맨틱 고려 opacity 단계). 셀 hover 시 작은 라벨(날짜 + 토큰 K/M — 그리드 하단 고정 캡션으로 표시, 팝오버 금지). 오늘 셀 테두리 강조. 등장 애니메이션: 셀 농도 0→값, 주 단위 stagger (가벼운 1회성).
3. **배치** — 추이 탭 세그먼트를 [7일 / 30일 / 잔디]로 확장 (잔디 선택 시 차트 대신 HeatmapView, statsStore 필요 — nil이면 항목 숨김). 패널 리사이즈(onResize) 동작 확인.
4. **enabledServices 반영** — 잔디 합산도 enabled 서비스만 (dailyTotalsByService에서 필터 후 합산).
