## W1: 코어 (TDD)

1. **Keychain 캐시** (`ClaudeLimits.swift` + 테스트)
   - `ClaudeCredentials`에 `expiresAt: Date?` 추가 — payload의 `claudeAiOauth.expiresAt`(epoch **밀리초**) 파싱.
   - `@MainActor final class ClaudeTokenProvider`: `token() -> String?` — 캐시된 자격증명이 있고 `expiresAt`이 nil이거나 now+60s 이후면 캐시 반환; 아니면 `ClaudeCredentials.fromKeychain()` 재조회 후 캐시. 테스트 가능하게 keychain 읽기를 클로저 주입(`reader: () -> ClaudeCredentials?`).
   - 테스트: expiresAt 파싱(ms), 캐시 적중 시 reader 미호출, 만료 시 재호출.
2. **displayName** — "Claude Code" → "Claude" (Models.swift). **주의**: TrendsTab `chartForegroundStyleScale` 키와 HoverCard 등 displayName 문자열 사용처 전부 동기화 필요 (grep "Claude Code").
3. **projectServiceBreakdown** (`UsageStore` + 테스트) — `projectServiceBreakdown(days:now:calendar:) -> [(project: String, byService: [ServiceID: Int], total: Int)]`, total 내림차순. 기존 projectBreakdown은 유지(외부 사용처 확인 후 가능하면 이걸로 대체).
4. **"~" 프로젝트명** — ClaudeLogParser/CodexLogParser(parseSessionMeta): cwd가 홈 디렉토리와 정확히 일치하면 project = "~". 홈 경로는 파서가 `NSHomeDirectory()` 직접 호출 대신 파라미터/static var로 주입 가능하게(테스트용). 테스트 각 1개.
5. **BriefingEngine** (`Sources/AIGlassCore/BriefingEngine.swift` + 테스트)
   - `enum Period: String, CaseIterable { case morning, lunch, evening }` — 시간대: morning 8..<11, lunch 12..<14, evening 18..<22 (로컬 캘린더 hour).
   - `struct BriefingData { yesterdayTokens: Int, yesterdayCost: Double, yesterdayTopProject: String?, todayTokens: Int, todayCost: Double, todayTopService: (ServiceID, share: Double)? }`
   - `@MainActor final class BriefingEngine`: `var lastFired: [Period: Date]` (외부 주입/저장은 호출자), `evaluate(now:data:) -> HUDEvent?` — 현재 시각이 어느 Period 구간이고 그 Period가 오늘 미발화면 발화(lastFired 갱신).
     - morning: 제목 "어제 사용 브리핑", 부제 "어제: {tokens} tokens · ~${cost}" (+ " · 주로 {project}")
     - lunch: 제목 "오늘 페이스", 부제 "이 페이스면 자정까지 ~{projected tokens} (~${projectedCost})" — projection = today / 경과시간비율 (자정~now 경과 비율로 외삽, 경과 < 4h면 발화 안 함)
     - evening: 제목 "오늘 사용 요약", 부제 "오늘: {tokens} tokens · ~${cost}" (+ " · {service} {share%} 비중")
     - tokens/cost 0이면 해당 Period 스킵. HUDEvent.Kind에 `case briefing(BriefingEngine.Period)` 추가 (EventEngine과 무관 — HUDEvent 타입만 공유).
   - 테스트: 시간대 판정, 하루 1회 발화, lunch 외삽 계산, 빈 데이터 스킵.

커밋: `feat: 토큰 캐시 + 브리핑 엔진 + 프로젝트 서비스 분해 (v0.4 코어)`

## W2: UI

1. **Theme 공식 컬러** — claude Color(red:0.85,green:0.47,blue:0.34), codex Color(red:0.063,green:0.64,blue:0.50), gemini Color(red:0.26,green:0.52,blue:0.96). safeGreen은 statusColor 전용으로 유지.
2. **HUD 위치 복원** — HUDView padding(10)으로, HUDPanel 기본 y `maxY - 4` (저장된 hudFrame 있으면 그대로 복원 유지).
3. **알약 로테이션 + 5h 기준** (HUDView WavePill)
   - 표시 서비스 목록 = limits가 있는 서비스 (claude, codex, gemini 고정 순). `index = Int(t / 6) % count` (TimelineView t 기준), 전환 시 페이드(.animation(.easeInOut, value: index)).
   - 표시 %: 그 서비스의 `.session5h` 윈도우 우선, 없으면 최댓값 윈도우. 점 색 = 서비스 공식색, % 색 = statusColor.
   - limits 빈 경우 기존 폴백(점 숨김, maxUsedPercent).
4. **EventCard briefing 아이콘** — morning `sun.max.fill`(yellow), lunch `gauge.with.needle`(blue), evening `moon.stars.fill`(indigo). briefing 카드는 자동 수축 10초(HUDState.show에 duration 파라미터 추가, 기본 6).
5. **대시보드 glass 패널** (`Sources/AIGlass/DashboardPanel.swift`, App.swift)
   - NSPopover 제거 → `DashboardPanelController`: NSPanel [.nonactivatingPanel,.borderless,.fullSizeContentView], FirstMouseHostingView, isOpaque false/clear, level .statusBar(메뉴바 클릭 컨텍스트) — 내용 `DashboardView`를 `.glassEffect(.regular, in: RoundedRectangle(cornerRadius: 22))` + padding으로 감쌈 (DashboardView 자체 폭 320 유지).
   - 위치: statusItem.button의 화면 좌표(`button.window!.convertToScreen(button.convert(button.bounds, to: nil))`) 기준 — 패널 top = 버튼 frame minY - 2, 우측 정렬(버튼 중앙 기준으로 화면 밖이면 클램프).
   - toggle: 열려 있으면 close. 열릴 때 refresh(). 닫기: 바깥 클릭(global monitor leftMouseDown/rightMouseDown → close), ESC(local monitor keyDown 53). 모니터는 열릴 때 등록, 닫힐 때 해제.
   - togglePopover() 호출처(메뉴바 좌클릭/HUD 탭/핫키/메뉴)는 시그니처 유지한 채 내부를 패널 토글로 교체. 기존 popover 프로퍼티 제거.
6. **프로젝트 탭 스택 바** — projectServiceBreakdown 사용: 행의 GaugeBar(purple) 대신 서비스 색 세그먼트 스택(HStack 비례 폭, 높이 6, Capsule clip). 캡션 "Claude · Codex 기준 (Gemini는 프로젝트 정보 없음)" 유지(이름 축약 반영).
7. **chartForegroundStyleScale/HoverCard 등 "Claude Code" 문자열 → displayName 변경 동기화.** (W1에서 처리됨 — 확인만)
8. **G9 웨이브 그라데이션 블렌딩** — allocateBars의 띠 배치는 유지하되 바별 단색 대신: 7개 바 HStack을 `.mask` 소스로 쓰고, fill은 `LinearGradient(stops:, startPoint: .leading, endPoint: .trailing)` — stops는 서비스 share 누적 위치에 해당 서비스 색 (경계에 ±0.08 오프셋 두 stop으로 부드러운 전환). 활동 없으면 기존 보라-파랑. allocateBars 함수와 테스트는 유지(색 stop 계산에 share 재사용).
9. **G10 호버 카드 리셋 카운트다운** — HoverCard 서비스 행: % 오른쪽 또는 아래에 9pt secondary로 `리셋 {EventEngine.countdown(...)}` — 그 서비스의 session5h(없으면 최댓값) 윈도우 resetsAt 기준. resetsAt nil이면 생략.
