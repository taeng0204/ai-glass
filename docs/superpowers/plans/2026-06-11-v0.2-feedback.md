| C2 | (컨트롤러) 최고사용률 카드 중복 | "현재 속도 N t/min" 카드로 교체 |

## H1: Core — 서비스별 burn rate + 프로젝트 귀속 (TDD)

**Files:** Models.swift, ClaudeLogParser.swift, CodexLogParser.swift(변경 없음), Collectors.swift, UsageStore.swift + 각 테스트

1. `TokenEvent`에 `public let project: String?` 추가 (init 마지막 파라미터, 기본값 nil — 기존 호출부 호환).
2. `ClaudeLogParser`: top-level `cwd` 추출 → `project = (cwd as NSString).lastPathComponent` (빈 문자열이면 nil).
3. `CodexCollector`: 파일별 session_meta 캐시 — 각 파일의 **첫 라인**이 `type=="session_meta"`면 `payload.cwd` 추출해 `[String: String]` (path→project) 캐시. 이벤트 생성 시 해당 파일의 project 부여. 증분 리더는 첫 라인을 한 번만 주므로, 캐시는 인스턴스 변수로 유지. (session_meta 파싱은 CodexLogParser에 `parseSessionMeta(line:) -> String?` 정적 함수 추가)
4. `UsageStore`:
   - `minuteBuckets`를 `[ServiceID: [Int: Int]]`로 변경. `tokensPerMinute(windowMinutes:now:)`는 전 서비스 합(기존 시그니처/동작 유지), `tokensPerMinute(service:windowMinutes:now:)` 추가.
   - `recentShare(windowMinutes: Int = 3, now: Date) -> [ServiceID: Double]` — 서비스별 비중(합 1.0, 활동 없으면 빈 dict).
   - `projectBreakdown(days:now:calendar:) -> [(project: String, tokens: Int)]` — project nil은 "기타"로 묶지 말고 제외.
   - 48h 버킷 정리는 서비스별 dict에 동일 적용.
5. 테스트: recentShare 비중 검증, projectBreakdown 집계/정렬, Claude 파서 project 추출, Codex session_meta 파싱, 기존 테스트 전부 유지.

커밋: `feat: 서비스별 burn rate + 프로젝트 귀속 (v0.2 코어)`

## H2: HUD — 밀착/호버/정체성/색 웨이브

**Files:** HUDView.swift, HUDPanel.swift

1. **F1 밀착**: HUDView `.padding(10)` → `.padding(.top, 2).padding(.trailing, 6)` 수준으로 축소, HUDPanel `setFrameTopLeftPoint` y를 `frame.maxY - 2`로. (시각적으로 메뉴바 바로 아래 ~4-6pt)
2. **F3 정체성**: WavePill에 최고 사용률 서비스 표시 — `store.limits`에서 maxUsedPercent를 가진 서비스 찾아 `Circle().fill(Theme.color(for: svc))` 6pt 점 + `Text("\(Int(percent))%")`(statusColor 유지). 점이 곧 "어느 서비스의 %인지"를 말한다.
3. **F4 색 웨이브**: `store.recentShare(now:)`로 7개 바에 서비스 색 배분 — share 비례로 바 개수 할당(내림 후 잔여는 최대 share 서비스에), 활동 없으면 기존 보라-파랑 유지. 각 바는 해당 서비스 색 그라데이션.
4. **F2 호버**: `HUDState`에 `var hovering = false` 추가. WavePill 컨테이너에 `.onHover { hudState.hovering = $0 }` → hovering이고 currentEvent 없으면 `HoverCard` 표시: 서비스 3행(색 점, 약칭 C/X/G 또는 풀네임, 미니 GaugeBar(statusColor), %). 카드도 glassEffect. 호버 이탈 시 0.15s 디바운스 후 수축(즉시 사라짐 방지 — Task 지연).
   - 주의: 호버 확장 시 카드가 패널 영역(280×130) 안에 들어가야 함. 카드 폭 ~210, 3행이면 충분.
5. EventCard 우선순위: currentEvent가 있으면 호버보다 우선.

커밋: `feat: HUD 밀착 + 호버 카드 + 서비스 색 웨이브 + % 정체성`

## H3: 대시보드 — 색 의미론/스택 추이/프로젝트별 탭/종료 메뉴

**Files:** DashboardView.swift, Theme.swift(필요시), main.swift

1. **F7**: ServiceRow — `primary`를 `windows.max { $0.usedPercent < $1.usedPercent }`로 (가장 긴급한 윈도우가 헤드라인). GaugeBar `tint:`를 `Theme.statusColor(percent:)`로 (서비스색 → 위험도색). 서비스 정체성은 앞의 색 점이 유지.
2. **F5**: TrendsTab — `Chart`에서 서비스별 스택: store에 `dailyTotalsByService(days:now:calendar:) -> [(day: Date, service: ServiceID, tokens: Int)]` 추가(H1에서 미리 넣어도 좋음 — H3에서 필요 명시), `BarMark(x: day, y: tokens)` + `.foregroundStyle(by: .value("서비스", service.displayName))` + `.chartForegroundStyleScale(["Claude Code": Theme.color(for: .claude), "Codex": ..., "Gemini": ...])`.
3. **F6**: ModelsTab → ProjectsTab — `store.projectBreakdown(days: 7, now: Date())` 상위 6개, 행: 프로젝트명(lastPathComponent) + 비중 GaugeBar(보라 유지) + %와 토큰량. 빈 상태 "최근 7일 데이터 없음". Tab enum: `개요/추이/프로젝트`.
4. **C2**: StatCard 3번째 "최고 사용률" → "현재 속도": `store.tokensPerMinute(windowMinutes: 3, now: Date())`를 K/M 포맷 + "t/min".
5. **C1**: main.swift — statusItem 우클릭 메뉴: `NSMenu`(항목: "대시보드 열기", 구분선, "AI Glass 종료" → `NSApp.terminate`). 좌클릭은 기존 팝오버 토글 유지 (`sendAction(on: [.leftMouseUp, .rightMouseUp])` + 이벤트 타입 분기 패턴).

커밋: `feat: 위험도색 게이지 + 스택 추이 + 프로젝트별 탭 + 종료 메뉴`
