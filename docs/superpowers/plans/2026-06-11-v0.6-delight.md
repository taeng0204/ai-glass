## Y1: 코어 (TDD)

1. **EventLog** (`Sources/AIGlassCore/EventLog.swift` + 테스트) — `@MainActor @Observable public final class EventLog`: `struct Record: Identifiable { id: UUID, event: HUDEvent, date: Date }`, `append(_ event:, at:)` 최신이 앞, cap 30. 테스트: 순서/cap.
2. **근사 리셋** (`UsageStore` + 테스트) — `approxFullReset(service:kind:now:) -> Date?`: 해당 서비스의 가장 최근 이벤트 시각 + 윈도우 길이(session5h=300분, weekly=7일; daily는 nil — 기존 resetsAt 있음). 이벤트 없으면 nil. 과거면 nil(이미 리셋됨). 테스트 2개.
3. **HUDEvent.Kind에 의존 없이** Record는 HUDEvent 재사용 (Equatable 이미 있음).

커밋: `feat: 이벤트 기록 + Codex 근사 리셋 (v0.6 코어)`

## Y2: 대시보드 UI

1. **개요 탭 2줄 게이지** — ServiceRow를 호버 카드 의미론으로: 서비스 헤더(점+이름+최댓값%) 아래 윈도우별 행(Kind.label + GaugeBar(statusColor) + % + 리셋). 리셋: resetsAt 있으면 countdown, 없으면 `store.approxFullReset` 결과를 `~`+countdown, 둘 다 없으면 생략. 기존 subline 제거. depletion 경고 라인 유지.
2. **톱니바퀴** — DashboardView 우상단(탭 Picker와 같은 줄 오른쪽) `gearshape` 버튼 → 클로저 주입(onSettings) → AppDelegate.openSettings().
3. **기록 탭** — Tabs: 개요/추이/프로젝트/기록. EventLog 주입. 행: kind 아이콘+제목(11pt)+부제(9pt, 1줄)+상대시각("3분 전" RelativeDateTimeFormatter). 빈 상태 "아직 알림이 없어요". **행 onHover → onReplay(record.event) 클로저** (AppDelegate가 hudState.show(event, duration: 2.5)로 연결 — 알약이 그 알림 모양으로 잠깐 모핑).
4. **애니메이션**
   - GaugeBar: `@State appeared=false` + onAppear → 채움 width 0→값 `.spring(duration:0.7)`, 행 인덱스별 delay 0.06*i (파라미터로).
   - StatCard 숫자: `.contentTransition(.numericText())` + onAppear 카운트업(값을 0→실제로 0.8초 단계 보간 — TimelineView 또는 Timer 8스텝).
   - 추이 차트: 데이터 적용을 onAppear 후 withAnimation으로 (0→값 자라기). 탭 재진입 시마다.
   - 프로젝트 스택: 폭 0→값 + stagger.
   - 탭 전환: 콘텐츠에 `.transition(.opacity.combined(with: .move(edge: .trailing)))` + animation(value: tab).
5. **서비스 필터(H4)** — DashboardView가 `enabled: Set<ServiceID>` 주입받아 모든 탭에서 필터. SettingsView에 "표시할 에이전트" 섹션(서비스별 Toggle, 최소 1개는 켜져 있어야 — 마지막 하나 끄기 방지). AppSettings.enabledServices: Set<ServiceID> (UserDefaults [String], 기본 전체).

커밋: `feat: 개요 2줄 + 기록 탭 + 톱니바퀴 + 애니메이션 + 에이전트 필터 (v0.6 대시보드)`

## Y3: HUD + 셸 배선

1. **⌘⇧E expand 고정** — GlobalHotKey 인스턴스 추가(kVK_ANSI_E). `HUDState.pinnedExpand: Bool` 토글 — true면 HoverCard 상시 (currentEvent 우선순위는 유지), 다시 누르면 해제. setHover와 OR 결합.
2. **알약 바운스** — 클릭 시 scaleEffect 0.94→1.0 스프링 (버튼 스타일 또는 onTap에서 @State 트리거).
3. **펄스 글로우** — (enabled 서비스 중) maxUsedPercent ≥ 90이면 알약에 빨강 글로우 호흡(shadow radius 6↔14, 2초 주기) — TimelineView t 기반.
4. **HUD 필터** — 로테이션/호버/웨이브 share/% 모두 enabledServices만.
5. **App 배선** — EventLog 인스턴스 → hudState.show 호출되는 모든 곳에서 eventLog.append (이벤트·브리핑 포함, 호버 리플레이 제외 — onReplay에서 append 금지). 메뉴바 % = enabled 서비스만의 max (updateStatusTitle 수정, store.maxUsedPercent에 서비스 필터 파라미터 추가 또는 App에서 계산). evaluateEvents의 limits도 enabled만 전달(꺼진 서비스 알림 미발화). 설정 창에 ⌘⇧E 표기 추가.
6. **README** 갱신.
