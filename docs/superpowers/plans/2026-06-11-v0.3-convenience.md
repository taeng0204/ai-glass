# AI Glass v0.3 — 편의 기능 전체 반영 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox 추적.

**Goal:** 사용자가 승인한 편의 기능 전부: ① .app 번들+로그인 시작 ② 한도 소진 예측 ③ HUD 위치 기억/숨김 + SQLite 30일 + 세션 리포트 + 비용 추정 + 글로벌 단축키 + 알림센터 + 설정 UI.

## V1: 코어 — 비용/예측/세션요약/SQLite (TDD)

**V1-1. CostEstimator** (`Sources/AIGlassCore/CostEstimator.swift` + 테스트)
- 단가표 (USD per MTok, **API 환산 추정치** — 주석에 출처/날짜 명시):

| model prefix | input | output |
|---|---|---|
| claude-fable | 10.0 | 50.0 |
| claude-opus | 5.0 | 25.0 |
| claude-sonnet | 3.0 | 15.0 |
| claude-haiku | 1.0 | 5.0 |
| gpt / codex (Codex 이벤트 model="gpt-codex") | 1.25 | 10.0 |
| gemini | 1.25 | 10.0 |
| (기타) | 3.0 | 15.0 |

- 캐시: cacheRead = 0.1 × input 단가, cacheCreation = 1.25 × input 단가 (Anthropic 기준을 전 모델에 적용 — 추정).
- API: `CostEstimator.cost(of: TokenEvent) -> Double`, `cost(of: [TokenEvent]) -> Double`. prefix 매칭은 lowercased contains가 아니라 hasPrefix 우선, 실패 시 contains("opus") 식 키워드 매칭.
- 테스트: opus 이벤트 단가 계산(수기 검증값), gpt-codex 매칭, 미지 모델 fallback.

**V1-2. DepletionEstimator** (`Sources/AIGlassCore/DepletionEstimator.swift` + 테스트)
- `UsageStore`에 `percentHistory: [ServiceID: [LimitWindow.Kind: [(date: Date, percent: Double)]]]` — `setLimits`에서 append, 최근 60분만 유지.
- 순수 함수: `DepletionEstimator.estimate(samples: [(Date, Double)], resetsAt: Date?, now: Date) -> Depletion?`
  - `Depletion { etaTo100: Date, willDepleteBeforeReset: Bool }`
  - 조건: 샘플 ≥ 3, 시간 범위 ≥ 5분, 최소제곱 기울기 > 0.05 %/min일 때만 추정. etaTo100 = now + (100 - 최신%) / slope 분.
  - willDepleteBeforeReset = resetsAt != nil && etaTo100 < resetsAt.
- 테스트: 선형 증가 샘플 → 정확한 ETA, 평탄 샘플 → nil, 리셋 전 소진 판정, 샘플 부족 → nil.

**V1-3. EventEngine 확장** (+ 테스트)
- `case depletionRisk(ServiceID)` 추가: evaluate에 `depletions: [ServiceID: Depletion]` 파라미터(기본 [:]) — willDepleteBeforeReset이면 발화, 서비스별 30분 쿨다운. 제목 "⚠️ {서비스} 소진 임박", 부제 "이 속도면 {countdown(etaTo100)} 후 소진 — 리셋 전에 막힘".
- `case sessionReport(ServiceID)` 추가: windowReset 발화 시 함께 만들지 **않고**, windowReset의 subtitle을 세션 요약으로 교체할 수 있도록 evaluate에 `reportProvider: ((ServiceID) -> String?)?` 파라미터(기본 nil) — reset 이벤트 생성 시 provider가 문자열을 주면 subtitle로 사용. (새 case 불필요 — windowReset 재활용. depletionRisk만 신규.)
- `thresholds`는 이미 public var — 변경 없음 (V3에서 설정값 주입).
- 우선순위: threshold > depletionRisk > reset > spike.
- 테스트: depletion 발화/쿨다운/우선순위, reportProvider subtitle 주입.

**V1-4. UsageStore.sessionSummary** (+ 테스트)
- `sessionSummary(service: ServiceID, from: Date, to: Date) -> String?` — 해당 기간 그 서비스 이벤트의 토큰합(K/M 포맷), 최다 프로젝트, 추정 비용($). 예: `"지난 세션: 4.2M tokens · 주로 ai-glass · ~$12.40"`. 이벤트 없으면 nil. 비용은 CostEstimator 사용.
- AppDelegate에서 windowReset 감지 시 from = 직전 윈도우 시작 추정(리셋 시각 - 5h) — V3에서 배선.

**V1-5. DailyStatsStore (SQLite)** (`Sources/AIGlassCore/DailyStatsStore.swift` + 테스트)
- `import SQLite3` (시스템 라이브러리, 의존성 추가 없음).
- `init(path: String)` — 디렉토리 생성, open, `CREATE TABLE IF NOT EXISTS daily_stats(day TEXT, service TEXT, model TEXT, project TEXT, input INTEGER, output INTEGER, cache_read INTEGER, cache_create INTEGER, PRIMARY KEY(day, service, model, project))`.
- `upsert(events: [TokenEvent], calendar: Calendar = .current)` — 이벤트를 (day,service,model,project)로 집계해 `INSERT OR REPLACE`. **주의: REPLACE는 누적이 아니라 대체** — 호출자는 해당 일자의 전체 이벤트를 넘겨야 함 (store.events가 8일 보존이므로 매번 최근 8일 전체를 넘기는 게 멱등).
- 조회: `dailyTotalsByService(days: Int, now: Date) -> [(day: Date, service: ServiceID, tokens: Int)]` (tokens = 4컬럼 합), `projectBreakdown(days: Int, now: Date) -> [(project: String, tokens: Int)]`, `totalCost(days: Int, now: Date) -> Double` (CostEstimator 단가로 컬럼별 계산 — model 컬럼 기준).
- day 포맷 "yyyy-MM-dd" (UTC 고정 — 컬럼 일관성).
- 테스트: 임시 경로 DB에 upsert→조회 왕복, REPLACE 멱등성(같은 데이터 2회 upsert → 동일 결과), 30일 범위 필터, 비용 계산.

커밋: `feat: 비용 추정 + 소진 예측 + 세션 요약 + SQLite 영구 통계 (v0.3 코어)`

## V2: 앱 셸 — 번들/자동시작/단축키/알림/설정 백본

**V2-2. HUD 위치 기억 + 숨김** (`HUDPanel.swift`, `App.swift`)
- 패널 `NSWindowDelegate.windowDidMove` (또는 frame 관찰)에서 `settings.hudFrame` 저장; init 시 저장값 있으면 `setFrame` 복원 (화면 밖이면 기본 위치로 — visibleFrame 교차 검사).

**V2-3. .app 번들 스크립트** (`Scripts/make-app.sh` + README 갱신)
- `swift build -c release` → `build/AIGlass.app/Contents/{MacOS,Resources}` 구성 → `Info.plist` 생성 (CFBundleIdentifier `io.taeng.aiglass`, CFBundleName AI Glass, LSUIElement true, CFBundleShortVersionString 0.3.0, NSHighResolutionCapable) → 바이너리 복사 → `codesign --force --deep -s - build/AIGlass.app` (ad-hoc) → 안내 출력 ("/Applications로 복사: cp -r ..."). 실행 권한 chmod +x.
- 검증: 스크립트 실행 → `open build/AIGlass.app` → 메뉴바/HUD 떠있는지 + `pkill AIGlass`.

**V2-4. 로그인 시 자동 시작** (`Sources/AIGlass/LaunchAtLogin.swift`)

**V2-5. 글로벌 단축키 ⌘⇧U** (`Sources/AIGlass/HotKey.swift`)

**V2-6. 알림센터 래퍼** (`Sources/AIGlass/Notifier.swift`)

## V3: UI 통합 — 설정 창/예측 표시/30일/세션 리포트/메뉴
